# lawyers_reminder_X5

## Техническое задание:

- Исполняемый exe-файл
- Приложение должно автоматически запускаться при перезагрузке/включении компьютера
- Приложение должно открыть xlsx-файл в формате:

| Объект | Дата окончания лицензии (B, факт) | Дата когда возможно подавать на лицензирование (C = B - 90 кд) | Крайний день подачи на продление (D = B - 16 раб дней) | Крайний день подачи на переоформление (E = D - 16 рабочих дней) 
| -------------- | ---------- | ---------- | ---------- | ---------- |
| Варшавское, 26 | 01.10.2026 | 03.07.2026 | 09.09.2026 | 18.08.2026 |

- Приложение должно обновить колонки в файле "Дата когда возможно подавать на лицензирование", "Крайний день подачи на продление", "Крайний день подачи на переоформление". Если этих колонок нет, то их нужно создать. Даты необходимо заполнить по тем объектам, где эти даты отсутствуют. Учитывать праздничные дни и выходные.

- Приложение должно найти все строки с объектами, срок в колонке "Крайний день подачи на переоформление" которых наступит через 3 **рабочих** дня и отправить пуш-уведомление в операционной системе пользователя со списком найденных объектов.


### Технологии

Слой | Технология | Зачем |
---- | ---------- | ------ |
| Упаковка | PyInstaller | Собрать в exe |
| Excel | openpyxl | Чтение/запись xlsx |
| Уведомления |	desktop_notifier | Push-уведомление в Windows |
| Логи | logging | Диагностика и сопровождение |
| Автозапуск | Windows Task Scheduler | Запуск при старте/по времени |

### Схема классов:
```text
MainApp
 ├── AppConfig
 ├── ReminderService
 │    ├── ExcelService
 │    └── NotificationService
 └── Logger
 ```

### Ответственность классов
MainApp — запускает приложение.
AppConfig — хранит настройки.
ReminderService — координирует бизнес-логику.
ExcelService — читает и пишет файл.
NotificationService — отправляет уведомление с помощью desktop_notifier.

**Скомпилировать .exe так:**
```
pyinstaller --onefile --noconsole --collect-all desktop_notifier --name lowyer_reminder app/main.py
```

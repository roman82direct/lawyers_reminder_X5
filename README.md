# lawyers_reminder_X5

- это должен быть исполняемый exe-файл
- Файл должен работать в фоновом режиме, автоматически запускаться при перезагрузке/включении компьютера
- Ежедневно в 00 часов 00 минут приложение должно открыть xls-файл в формате:
№ п/п | Название объекта | Адрес объекта | Дата окончания лицензии

- Приложение должно обновить колонку в файле "Дата подачи заявления на продление". Если этой кологки нет, то ее нужно создать. Эта дата рассчитывается по формуле: Дата окончания лицензии - 15 **календарных** дней и пересохранить файл. Дату подачи заявления на продление необходимо заполнить по тем объектам, где эта дата отсутствует.

- Приложение должно найти все строки с объектами, срок подачи заявления на продление лицензии которых наступит через 10 **календарных** дней

- Приложение должно отправить пуш-уведомление в операционной системе пользователя с полным списком найденных объектов, срок подачи заявления на продление лицензии которых наступит через 10 **календарных** дней

Слой | Технология | Зачем |
---- | ---------- | ------ |
Упаковка | PyInstaller | Собрать в exe |
Автозапуск | Windows Task Scheduler | Надежный запуск при старте/по времени |
Excel | openpyxl | Чтение/запись xlsx |
Планирование | APScheduler или Task Scheduler | Ежедневный запуск в 00:00 |
Уведомления |	plyer / winotify | Push-уведомление в Windows |
Логи | logging | Диагностика и сопровождение |

Ежедневный запуск через Планировщик Windows. Сам exe будет стартовать в 00:00, отрабатывать сценарий и завершаться; при необходимости отдельной задачей можно запускать его при входе в систему для проверки состояния или для ручного режима. Такой подход хорошо сочетается с pythonw.exe/PyInstaller и упрощает отладку

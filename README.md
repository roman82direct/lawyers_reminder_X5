# lawyers_reminder_X5

## Техническое задание:

- Исполняемый exe-файл
- Приложение должно автоматически запускаться при перезагрузке/включении компьютера или ежедневно в 00 часов 00 минут
- Приложение должно открыть xlsx-файл в формате:

| Объект | Дата окончания лицензии (B, факт) | Дата когда возможно подавать на лицензирование (C = B - 90 кд) | Крайний день подачи на продление (D = B - 16 раб дней) | Крайний день подачи на переоформление (E = D - 16 рабочих дней) 
| -------------- | ---------- | ---------- | ---------- | ---------- |
| Варшавское, 26 | 01.10.2026 | 03.07.2026 | 09.09.2026 | 18.08.2026 |

- Приложение должно обновить колонки в файле "Дата когда возможно подавать на лицензирование", "Крайний день подачи на продление", "Крайний день подачи на переоформление". Если этих колонок нет, то их нужно создать. Даты необходимо заполнить по тем объектам, где эти даты отсутствует. Учитывать праздничные дни.

- Приложение должно найти все строки с объектами, срок в колонке "Крайний день подачи на переоформление" которых наступит через 3 **рабочих** дня и отправить пуш-уведомление в операционной системе пользователя с полным списком найденных объектов.


### Технологии

Слой | Технология | Зачем |
---- | ---------- | ------ |
| Упаковка | PyInstaller | Собрать в exe |
| Excel | openpyxl | Чтение/запись xlsx |
| Автозапуск | Windows Task Scheduler | Надежный запуск при старте/по времени |
| Уведомления |	desktop_notifier | Push-уведомление в Windows |
| Логи | logging | Диагностика и сопровождение |
